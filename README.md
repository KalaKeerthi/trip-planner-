# 📖 About The Project

The **Travel Planner Web Application** is a full-stack travel management platform designed to help users explore tourist destinations, search places city-wise, and plan trips efficiently.

This project integrates:
- 🌍 Google Maps API
- 🔐 User Authentication
- 🏙️ Tourist Place Search
- 📩 Contact / Guide Request System

It is built as a modern web application using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**.

---

# ✨ Features

## 🌆 Tourist Destination Search
- Search famous tourist places by city

---

# 🔑 Google Maps API Setup

1. Create API key from Google Cloud Console
2. Enable:
   - Maps JavaScript API
   - Places API
3. Add your API key inside:

```javascript
script.js
```

Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```

---

# 🌐 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/places/:city` | Get tourist places |
| POST | `/auth/register` | Register user |
| POST | `/auth/login` | Login user |
| POST | `/contact` | Send contact request |
